Pending Review Queue

Upload an incoming requirements file (e.g. a RegWatch/OpenLaws batch). Each incoming record is matched by Record ID against the current dataset. New IDs can be added directly; records whose content differs from an existing record are queued as conflicts with a field-by-field diff. Nothing is applied automatically — for each conflict you choose to keep existing, use incoming, or manually reconcile, then apply your resolutions.
