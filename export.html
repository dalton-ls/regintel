Export

Download the current dataset as JSON. The Requirements export reflects every local edit and added record layered on top of requirements.json. Choose which datasets to export, then download.

This tool does not commit anything to the repository. It downloads files to your machine; you review them and commit into version control yourself — e.g. replace the repo's requirements.json with the downloaded file, then git add / commit / push.
